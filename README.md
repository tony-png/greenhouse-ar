# Greenhouse AR

See the wooden lattice-rib tunnel greenhouse at true 1:1 scale in your own yard.

Open **https://tony-png.github.io/greenhouse-ar/** in Chrome on an ARCore Android phone and tap **View in your backyard**.

- `greenhouse.glb`: the finished greenhouse (polycarbonate cladding, end walls, dwarf walls) on its gravel pad
- `frame.glb`: arches and purlins only
- Units are metres, the model stands on y = 0, Draco-compressed; shown with [model-viewer](https://modelviewer.dev) 4.3.1.

A planning model, not a structural design.
